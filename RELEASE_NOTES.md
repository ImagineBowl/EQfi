## EQfi v1.0.0

AI-powered system-wide equalizer for macOS.

### Requirements
- macOS 14.2 or later
- [Ollama](https://ollama.com) with a Llama model (e.g. `ollama pull llama3.2:3b`)
- System Audio Recording permission (prompted on first enable)

### Install
1. Download `EQfi-1.0.0.dmg`
2. Open the DMG and drag **EQfi** to **Applications**
3. Launch EQfi from Applications (menu bar icon)

### Supported now-playing apps
Spotify, Apple Music, Overcast, Pocket Casts, Apple Podcasts

### Notes
- Genre lookup uses the hosted EQfi API (Spotify + MusicBrainz)
- Browser playback (e.g. YouTube in Chrome) is not supported yet
